# Scripting and Automating Developer Credentials

Demos for the 2026 talk "Scripting and Automating Developer Credentials" at Esri Dev and Tech Summit.

ArcGIS REST JS and the ArcGIS API for Python are compact and easy-to-use wrappers around the ArcGIS REST APIs that make working with developer credentials in your applications a breeze. Speakers show how to use ArcGIS REST JS and the ArcGIS API for Python to manage your developer credentials.
